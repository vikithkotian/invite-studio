
  # Mini Canva Invitation Editor UI

  This is a code bundle for Mini Canva Invitation Editor UI. The original project is available at https://www.figma.com/design/brPqeyR34afXjGwckddptS/Mini-Canva-Invitation-Editor-UI.

  ## Running the code

  The frontend lives in `FrontEnd/` and the API lives in `Backend/`.

  From `FrontEnd/`, run `npm i` to install the frontend dependencies and `npm run dev` to start the UI.

  From `Backend/`, run `npm i` and `npm run dev` to start the API.
